نظام رفع الملفات - صور الموظفين وشعارات المؤسسات

February 7, 2026

📖 نظرة عامة

نظام رفع الملفات يتيح رفع صور الموظفين (للتعرف على الوجه) وشعارات المؤسسات. يدعم النظام معالجة الصور تلقائياً بما في ذلك تغيير الحجم والضغط والتحويل للصيغ المناسبة.

🔒 التوثيق: جميع الطلبات تتطلب Bearer Token في الهيدر
⚠️ الصلاحيات:
  • رفع صور الموظفين: admin+ أو صلاحية employees.update
  • رفع شعارات المؤسسات: super_admin أو admin لنفس المؤسسة

⚙️ المواصفات التقنية

📦 البنية التحتية

المكون التقنية الوصف
Multer v1.4.5-lts.1 معالجة multipart/form-data
Sharp v0.33.5 معالجة وضغط الصور
التخزين Local Disk uploads/ directory

📏 حدود الملفات

نوع الملف الحد الأقصى الصيغ المدعومة المعالجة
صور الموظفين 5 MB JPEG, PNG, GIF تحويل لـ JPEG 400x400
شعارات المؤسسات 2 MB JPEG, PNG, GIF تحويل لـ PNG 300x300
ملفات CSV 10 MB CSV بدون معالجة
مستندات 10 MB × 5 ملفات PDF, DOC, DOCX بدون معالجة

🖼️ معالجة الصور

{ "employeePhoto": { "dimensions": "400x400", "format": "JPEG", "quality": 85, "fit": "cover", "purpose": "Face recognition optimization" }, "organizationLogo": { "dimensions": "300x300", "format": "PNG", "background": "transparent", "fit": "contain", "purpose": "Professional branding" } }

👤 صور الموظفين

POST /api/employees/:id/photo

رفع صورة موظف (للتعرف على الوجه)

📥 Parameters

  • :id مطلوب - معرف الموظف
  • photo مطلوب - ملف الصورة (multipart/form-data)

📤 Response (200 OK)

{ "success": true, "message": "تم رفع صورة الموظف بنجاح", "data": { "id": 1, "name": "Ahmed Mohammed", "employee_no": "EMP001", "photo_url": "/uploads/employees/photos/processed-1234567890.jpg", "department": "IT", "position": "Developer" } }
💡 ملاحظات:
  • الصورة تُعالج تلقائياً: تحويل لحجم 400x400، صيغة JPEG، جودة 85%
  • الصورة القديمة تُحذف تلقائياً عند رفع صورة جديدة
  • يُسجل الإجراء في AuditLog
GET /api/employees/:id/photo

الحصول على صورة موظف

📥 Parameters

  • :id مطلوب - معرف الموظف

📤 Response

  • 200 OK: ملف الصورة (Content-Type: image/jpeg)
  • 404 Not Found: "لا توجد صورة لهذا الموظف"
DELETE /api/employees/:id/photo

حذف صورة موظف

📥 Parameters

  • :id مطلوب - معرف الموظف

📤 Response (200 OK)

{ "success": true, "message": "تم حذف صورة الموظف بنجاح", "data": { "id": 1, "name": "Ahmed Mohammed", "photo_url": null } }

🏢 شعارات المؤسسات

POST /api/organizations/:id/logo

رفع شعار مؤسسة

📥 Parameters

  • :id مطلوب - معرف المؤسسة
  • logo مطلوب - ملف الشعار (multipart/form-data)

📤 Response (200 OK)

{ "success": true, "message": "تم رفع شعار المؤسسة بنجاح", "data": { "id": 1, "name": "شركة النظام التجريبية", "logo_url": "/uploads/organizations/logos/logo-1234567890.png", "subscription_plan": "pro", "is_active": true } }
💡 ملاحظات:
  • الشعار يُعالج تلقائياً: تحويل لحجم 300x300، صيغة PNG مع شفافية
  • super_admin يمكنه رفع شعار لأي مؤسسة
  • admin يمكنه رفع شعار لمؤسسته فقط
GET /api/organizations/:id/logo

📥 Parameters

📤 Response

  • 404 Not Found: "لا يوجد شعار لهذه المؤسسة"
DELETE /api/organizations/:id/logo

حذف شعار مؤسسة

📥 Parameters

💻 أمثلة برمجية

JavaScript (Axios)

// رفع صورة موظف const formData = new FormData(); formData.append('photo', fileInput.files[0]); const response = await axios.post( 'http://localhost:3000/api/employees/1/photo', formData, { headers: { 'Authorization': `Bearer ${token}`, 'Content-Type': 'multipart/form-data' } } ); console.log('Photo uploaded:', response.data.data.photo_url);

cURL

curl -X POST \ http://localhost:3000/api/employees/1/photo \ -H "Authorization: Bearer YOUR_TOKEN" \ -F "photo=@employee-photo.jpg"

Node.js (form-data)

import FormData from 'form-data'; import fs from 'fs'; import axios from 'axios'; const form = new FormData(); form.append('logo', fs.createReadStream('company-logo.png')); const response = await axios.post( 'http://localhost:3000/api/organizations/1/logo', form, { headers: { 'Authorization': `Bearer ${token}`, ...form.getHeaders() } } );

⚠️ معالجة الأخطاء

أكواد الأخطاء الشائعة

الكود الخطأ الحل
400 لم يتم إرفاق ملف تأكد من إرسال الملف في حقل 'photo' أو 'logo'
400 نوع الملف غير مدعوم استخدم JPEG, PNG, أو GIF فقط
400 حجم الملف كبير جداً تأكد من أن الملف أقل من الحد المسموح
401 غير موثق أرسل Bearer Token صحيح في الهيدر
403 غير مصرح تحقق من صلاحياتك (admin أو employees.update)
404 الموظف/المؤسسة غير موجود تأكد من صحة المعرف (ID)
500 فشل معالجة الصورة تأكد من أن الصورة صالحة وليست تالفة

مثال على رسالة خطأ

{ "success": false, "message": "نوع الملف غير مدعوم", "errors": [ { "field": "photo", "message": "يجب أن يكون الملف من نوع JPEG, PNG, GIF" } ] }

🔐 الأمان

✔️ إجراءات الأمان المُطبقة:
  • Whitelist للأنواع: فقط JPEG, PNG, GIF, PDF, DOC, CSV مسموح
  • حدود الحجم: منع رفع ملفات ضخمة (2-10 MB حسب النوع)
  • تنظيف أسماء الملفات: إزالة محارف خطيرة ومنع path traversal
  • التوثيق: جميع الطلبات تتطلب JWT token
  • الصلاحيات: التحقق من role وorganization_id
  • Audit Logging: تسجيل جميع عمليات الرفع والحذف
  • معالجة آمنة: استخدام Sharp لفحص ومعالجة الصور
⚠️ تحذيرات:
  • لا ترفع ملفات من مصادر غير موثوقة
  • تحقق من صحة الملفات قبل الإرسال
  • استخدم HTTPS في الإنتاج لحماية البيانات
