// ✅ CORRECT
success(res, data, message, statusCode)

// ❌ WRONG (OLD)
success(res, message, data, statusCode)

التأثير: جميع الـ responses الآن تتبع البنية الصحيحة

🌐 API Endpoints

GET

1. Get Statistics Overview

/api/employees/stats/overview

الوصف: جلب إحصائيات شاملة عن الموظفين (إجمالي، نشط، غير نشط، عدد الأقسام)

الصلاحية: All authenticated users

Response:

{
  "success": true,
  "message": "تم جلب الإحصائيات بنجاح",
  "data": {
    "total": 5,
    "active": 4,
    "inactive": 1,
    "departments_count": 2
  }
}
GET

2. Get Departments List

/api/employees/departments/list

الوصف: جلب قائمة الأقسام مع عدد الموظفين في كل قسم

الصلاحية: All authenticated users

Response:

{
  "success": true,
  "message": "تم جلب قائمة الأقسام بنجاح",
  "data": [
    { "department": "IT", "employee_count": 3 },
    { "department": "HR", "employee_count": 2 }
  ]
}
GET

3. Get All Employees (with Filtering)

/api/employees?page=1&limit=10&search=Ahmed&department=IT&is_active=true

الوصف: جلب قائمة الموظفين مع دعم البحث، الترشيح، والترتيب

الصلاحية: All authenticated users

Query Parameters:

Parameter Type Required Default Description
page Integer Optional 1 رقم الصفحة
limit Integer Optional 10 عدد العناصر في الصفحة (Max: 100)
search String Optional - البحث في الاسم ورقم الموظف
department String Optional - تصفية حسب القسم
is_active Boolean Optional - تصفية حسب الحالة (true/false)
sort_by String Optional created_at حقل الترتيب (name, employee_no, created_at)
sort_order String Optional DESC اتجاه الترتيب (ASC/DESC)

Response:

{
  "success": true,
  "message": "تم جلب قائمة الموظفين بنجاح",
  "data": {
    "employees": [ {...}, {...} ],
    "pagination": {
      "total": 25,
      "currentPage": 1,
      "totalPages": 3,
      "limit": 10
    }
  }
}
GET

5. Create New Employee

/api/employees

الوصف: إنشاء موظف جديد

الصلاحية: Admin, Manager

Request Body:

{
  "employee_no": "EMP002",
  "name": "Sara Ali",
  "department": "HR",
  "email": "sara@demo.test",
  "phone": "07700000002",
  "hire_date": "2024-02-01",
  "position": "HR Manager",
  "national_id": "12345678901"
}

Required Fields:

  • employee_no - رقم الموظف (فريد)
  • name - اسم الموظف (2-255 حرف)
  • department - القسم

Response (201 Created):

{
  "success": true,
  "message": "تم إنشاء الموظف بنجاح",
  "data": {
    "id": 2,
    "employee_no": "EMP002",
    "name": "Sara Ali",
    "department": "HR",
    ...
  }
}
PUT

Common HTTP Status Codes

Status Code الحالة متى يحدث
200 OK نجاح العملية
201 Created إنشاء ناجح
400 Bad Request بيانات غير صحيحة
401 Unauthorized غير مصرح - token مفقود أو غير صالح
403 Forbidden ممنوع - المستخدم ليس لديه صلاحية
404 Not Found الموظف غير موجود
409 Conflict employee_no مكرر
429 Too Many Requests تجاوز Rate Limit
500 Internal Server Error خطأ في السيرفر
