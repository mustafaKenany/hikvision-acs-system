# دليل التشغيل السريع - نظام الحضور والانصراف

## 🚀 البدء السريع

### الخطوة 1: تشغيل Backend

```bash
cd backend
npm install
npm start
```

Backend يعمل على: `http://localhost:3000`

### الخطوة 2: تشغيل Frontend

```bash
cd frontend
npm install
npm run dev
```

Frontend يعمل على: `http://localhost:5173`

## 📝 الخطوات التفصيلية

### 1. إنشاء جدول دوام جديد

1. افتح المتصفح على `http://localhost:5173`
2. سجل دخول بحساب admin
3. اذهب إلى "جداول الدوام" من القائمة الجانبية
4. اضغط "إضافة جدول دوام"
5. املأ البيانات:
   ```
   الاسم: دوام الموظفين الإداريين
   وقت البداية: 08:00:00
   وقت النهاية: 17:00:00
   أيام العمل: أحد، إثنين، ثلاثاء، أربعاء، خميس
   الساعات المطلوبة: 8
   فترة السماح للتأخير: 15
   ```
6. اضغط "حفظ"

### 2. تعيين موظفين على جدول الدوام

1. من صفحة جداول الدوام، اضغط أيقونة "الموظفين" (👥)
2. اختر الموظفين من القائمة
3. حدد تاريخ البداية (مثال: 2024-01-01)
4. اضغط "تعيين الموظفين"

### 3. محاكاة تسجيل حضور

يمكنك استخدام Postman أو curl لإضافة سجلات حضور:

```bash
# تسجيل دخول
curl -X POST http://localhost:3000/api/attendance-logs \
-H "Authorization: Bearer YOUR_TOKEN" \
-H "Content-Type: application/json" \
-d '{
  "employee_id": 1,
  "device_id": 1,
  "event_type": "check_in",
  "event_time": "2024-01-15T08:05:00"
}'

# تسجيل خروج
curl -X POST http://localhost:3000/api/attendance-logs \
-H "Authorization: Bearer YOUR_TOKEN" \
-H "Content-Type: application/json" \
-d '{
  "employee_id": 1,
  "device_id": 1,
  "event_type": "check_out",
  "event_time": "2024-01-15T17:10:00"
}'
```

> **ملاحظة**: سيتم حساب الحضور تلقائياً عند إضافة سجل الخروج!

### 4. حساب الحضور يدوياً (اختياري)

إذا كنت تريد إعادة حساب الحضور:

1. اذهب إلى "تقارير الحضور"
2. اختر نطاق التاريخ
3. اضغط "حساب الحضور"

أو باستخدام API:

```bash
curl -X POST http://localhost:3000/api/reports/attendance/calculate \
-H "Authorization: Bearer YOUR_TOKEN" \
-H "Content-Type: application/json" \
-d '{
  "start_date": "2024-01-01",
  "end_date": "2024-01-31"
}'
```

### 5. عرض التقارير

1. اذهب إلى "تقارير الحضور" من القائمة
2. اختر نوع التقرير:
   - **تقرير يومي**: عرض حضور جميع الموظفين ليوم واحد
   - **تقرير شهري**: ملخص شهري لكل موظف
   - **تقرير التأخيرات**: جميع حالات التأخير
   - **تقرير الساعات الإضافية**: جميع الساعات الإضافية
   - **تقرير الغياب**: جميع حالات الغياب
3. اختر نطاق التاريخ
4. اضغط "تطبيق الفلاتر"

### 6. تصدير التقرير

1. بعد عرض التقرير، اضغط "تصدير Excel"
2. سيتم تحميل ملف Excel تلقائياً

## 🧪 اختبار النظام

### اختبار الـ APIs

```bash
cd backend
node test-work-schedule.js
```

ستظهر نتائج الاختبار بألوان:
- ✅ أخضر: نجح
- ❌ أحمر: فشل

### سيناريو الاختبار الكامل

#### 1. إنشاء دوام ثابت

```http
POST /api/work-schedules
{
  "name": "دوام الإدارة",
  "start_time": "08:00:00",
  "end_time": "17:00:00",
  "work_days": [0, 1, 2, 3, 4],
  "expected_hours": 8,
  "late_grace_minutes": 15,
  "is_flexible": false
}
```

#### 2. تعيين 5 موظفين

```http
POST /api/work-schedules/1/assign-employees
{
  "employee_ids": [1, 2, 3, 4, 5],
  "effective_from": "2024-01-01"
}
```

#### 3. إضافة سجلات حضور لـ 5 أيام

```bash
# اليوم 1: حضور في الموعد
check_in: 08:00, check_out: 17:00 → Present, 8 hours

# اليوم 2: تأخير 20 دقيقة
check_in: 08:20, check_out: 17:10 → Late, 7.83 hours

# اليوم 3: حضور + ساعات إضافية
check_in: 08:00, check_out: 19:00 → Present, 10 hours (2 overtime)

# اليوم 4: نصف يوم
check_in: 08:00, check_out: 12:00 → Half Day, 4 hours

# اليوم 5: غياب
(لا يوجد تسجيل) → Absent
```

#### 4. عرض التقرير اليومي

```http
GET /api/reports/attendance/daily?date=2024-01-15
```

#### 5. عرض التقرير الشهري

```http
GET /api/reports/attendance/monthly?year=2024&month=1
```

## 📊 فهم النتائج

### حالات الحضور (Status)

| الحالة | الشرط | الوصف |
|--------|-------|-------|
| **present** | ≥90% من الساعات المطلوبة + لا تأخير | حضور كامل |
| **late** | ≥90% من الساعات + تأخير | حضور مع تأخير |
| **half_day** | 50%-90% من الساعات | نصف يوم |
| **absent** | <50% من الساعات أو لا يوجد تسجيل | غياب |
| **holiday** | خارج أيام العمل | عطلة |

### حساب التأخير

```
هل متأخر = (وقت الدخول > وقت البداية + فترة السماح)

مثال:
- وقت البداية: 08:00
- فترة السماح: 15 دقيقة
- الحد الأقصى المسموح: 08:15

- دخول 08:10 → ليس متأخراً ✅
- دخول 08:20 → متأخر 5 دقائق ❌
```

### حساب الساعات الإضافية

```
ساعات إضافية = max(0, ساعات العمل - الساعات المطلوبة)

مثال:
- الساعات المطلوبة: 8
- ساعات العمل: 10
- ساعات إضافية: 2 ✅
```

### حساب ساعات العمل

```
ساعات العمل = (وقت الخروج - وقت الدخول) - وقت الاستراحة

مثال:
- دخول: 08:00
- خروج: 17:00
- إجمالي: 9 ساعات
- استراحة: 1 ساعة
- ساعات العمل: 8 ساعات
```

##  Troubleshooting

### مشكلة: "الموظف ليس له جدول دوام"

**الحل**:
1. تأكد من تعيين الموظف على جدول دوام
2. تأكد من أن التاريخ ضمن فترة التعيين (effective_from/effective_until)
3. تأكد من أن الجدول نشط (is_active = true)

### مشكلة: "لا يتم حساب الساعات الإضافية"

**الحل**:
1. تأكد من وجود check_out (لا يمكن حساب بدون خروج)
2. تأكد من أن ساعات العمل أكثر من expected_hours
3. جرّب إعادة الحساب يدوياً

### مشكلة: "التقرير فارغ"

**الحل**:
1. تأكد من نطاق التاريخ الصحيح
2. تأكد من وجود بيانات في AttendanceSummary
3. اضغط "حساب الحضور" لتوليد البيانات

## 🎯 نصائح التطوير

### 1. إعدادات الـ Grace Period

- للشركات الصارمة: `late_grace_minutes: 0`
- للشركات المرنة: `late_grace_minutes: 30`

### 2. الدوام المرن

إذا كنت تريد دوام مرن (Remote Work):
```json
{
  "is_flexible": true,
  "expected_hours": 8,
  "work_days": [0, 1, 2, 3, 4, 5, 6]
}
```

### 3. دوام جزئي (Part-time)

```json
{
  "expected_hours": 4,
  "half_day_hours": 2
}
```

### 4. دوام ليلي (Night Shift)

```json
{
  "start_time": "22:00:00",
  "end_time": "06:00:00",
  "expected_hours": 8
}
```
